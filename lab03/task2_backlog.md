## Must
- As a student, I want to browse available events so that I can find events to attend.
	- **Priority:** Must. The brief explicitly requires students to browse events.
- As a student, I want to view an event's information so that I can decide whether to register.
	- **Priority:** Must. Event information is needed to make browsing useful and support registration.
- As a student, I want to register for an event so that I can attend it.
	- **Priority:** Must. The brief explicitly requires students to register.
- As a student, I want to get reminders about events so that I remember them.
	- **Priority:** Must. The brief explicitly requires students to get reminders.
- As an admin, I want to add events so that students can browse and register for them.
	- **Priority:** Must. The brief explicitly requires admins to add events.
- As an admin, I want to remove events so that they are no longer available to students.
	- **Priority:** Must. The brief explicitly requires admins to remove events.

## Should
- As a student, I want to see which events I have registered for so that I can keep track of them.
	- **Priority:** Should. This supports registration but is not explicitly required by the brief.
- As an admin, I want to update an event's information so that I can correct details without removing the event.
	- **Priority:** Should. Updating events is useful, but the brief only specifies adding and removing them.

## Could
- As a student, I want to filter events by date so that I can find events happening when I am available.
	- **Priority:** Could. Filtering could make browsing easier but is not required by the brief.
- As a student, I want to choose when reminders arrive so that they fit my schedule.
	- **Priority:** Could. Reminder timing preferences are optional; the brief only requires reminders.

## Won't
- As an admin, I want to view event attendance analytics so that I can compare event popularity.
	- **Priority:** Won't. Analytics are outside the project brief and are excluded from this release.
- As a student, I want to receive event recommendations so that I can discover events based on my interests.
	- **Priority:** Won't. Recommendations are outside the project brief and are excluded from this release.
